# Personal Portfolio 

Built with **Next.js** and **React**.  
Showcases my background, skills, projects, and a contact form.

## Tech Stack
- **Next.js 14**
- **React 18**
- **CSS Modules**
- **Deployed on Vercel**

## Project Structure
pages/ → All site pages (Home, Resume, Skills, Contact)
components/ → Reusable UI components (Header, Footer, SectionCard, Hero)
styles/ → CSS Modules for styling
public/ → Static assets

## Deployment
This site is deployed via Vercel.
